# Simulador de Urna Eletrônica 2026

O Simulador de Urna Eletrônica 2026 é um projeto educacional e lúdico desenvolvido para instruir crianças sobre o funcionamento do processo eleitoral brasileiro, simulando com fidelidade visual e sonora a urna verdadeira no 1º turno das Eleições 2026 a partir de dados públicos do TSE para o estado do Ceará, permitindo consultar candidatos e votar na sequência oficial dos seis cargos (Deputado Federal, Deputado Estadual/Distrital, dois Senadores, Governador e Presidente).
